#  📌 Sobre o Projeto
Este repositório contém as soluções detalhadas da **Lista 04** da disciplina de Estrutura de Dados. O foco principal foi o desenvolvimento de lógica algorítmica aplicada, utilizando **Arrays (Vetores)**, **Métodos Estáticos** e **Modularização**.

---

# 📂 Organização dos Desafios

| Questão | 🛠️ Funcionalidade | 🧠 Conceito Chave |
| :--- | :--- | :--- |
| **Q1** | **Gestão de Notas** | Iteração de Vetores e Acumuladores |
| **Q2** | **Caixa Eletrônico (Saque)** | Divisão Inteira e Operador Resto (`%`) |
| **Q3** | **Validador de Segurança** | Manipulação de `String` e `Character` |
| **Q4** | **Conversor de Tempo** | Aritmética Computacional (Seg → H:M:S) |
| **Q5** | **Busca de Duplicados** | Loops Aninhados e Complexidade de Algoritmos |
| **Q6** | **Inversor de Vetor** | Algoritmo de Troca (*Swap*) com Ponteiros |
